# Hardware

## Core Hardware

The exact components will be finalized during prototyping.

| Component | Purpose | Status |
|---|---|---|
| Electric guitar | Base instrument | ✅ |
| Microcontroller | Main controller | 🔄 |
| Sensors | User/input detection | 🔄 |
| LEDs | Visual feedback | 🔄 |
| Controls | User interaction | 🔄 |
| Power system | Battery / regulation | 🔄 |
| Enclosure | Mechanical protection | 🔄 |

## Hardware Selection Criteria

Components should be:

- Compact enough for guitar integration
- Low power where practical
- Easy to replace
- Well documented
- Compatible with the chosen microcontroller
- Safe to integrate into the instrument

## Prototype Philosophy

The first prototype should prioritize learning over appearance. Breadboard/prototype wiring can be used initially, followed by a cleaner assembly once the electronics are validated.
